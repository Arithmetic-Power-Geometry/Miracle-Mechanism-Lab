# Public communication notes

## Recommended project description

**Anomalous Capability Simulator (ACS)** is an open-source computational research tool that converts hypothetical unusual-capability scenarios into explicit observables, parameterized models, competing explanations, and discriminating measurements.

## Neutrality statement

The canonical software uses project-created, plain-English experiment and scenario labels. It does not classify people, communities, worldviews, or cultural systems.

## What the simulator can claim

- It can simulate stipulated model conditions.
- It can compare declared candidate mechanisms.
- It can calculate quantitative outputs relative to explicit model assumptions.
- It can identify measurements that distinguish synthetic alternatives.
- It can generate synthetic datasets for software and methodology testing.

## What it must not claim

- It does not prove that extraordinary capabilities exist.
- It does not physically create modeled objects or events.
- It does not infer a unique real-world mechanism from a simulated output.
- Synthetic benchmark results are not empirical evidence.

This wording supports accurate public description of the software. It is not legal advice.
