# Public communication notes

## Recommended project description

**Anomalous Capability Simulator** is an open-source computational research tool that converts hypothetical extraordinary-capability scenarios into state transitions, constraint residuals, ordinary competing explanations, and discriminating measurements.

## Neutrality statement

The project does not test, interpret, endorse, reject, rank, or attribute claims to any religion, scripture, spiritual community, or practitioner. Its capability labels are project-created abstract research terms.

## What the simulator can claim

- It can simulate hypothetical world-state changes.
- It can compare stipulated mechanisms.
- It can calculate residuals relative to declared physical/information constraints.
- It can identify measurements that distinguish model alternatives.
- It can generate synthetic datasets for software and methodology testing.

## What it must not claim

- It does not prove that extraordinary powers exist.
- It does not physically create objects or events.
- It does not validate or invalidate a religion or spiritual tradition.
- Synthetic benchmark results are not empirical evidence.

This wording is intended to support respectful public communication. It is not legal advice.
